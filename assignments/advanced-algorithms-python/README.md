# 📘 Assignment: Advanced Algorithms in Python

## 🎯 Objective

Implement and analyze advanced sorting and searching algorithms in Python. You'll learn about algorithm efficiency, time complexity analysis, and practical applications of data structures.

## 📝 Tasks

### 🛠️ Implement Sorting Algorithms

#### Description
Create implementations of common sorting algorithms and compare their performance.

#### Requirements
Completed program should:

- Implement at least 3 sorting algorithms (e.g., quicksort, mergesort, heapsort)
- Include a function to measure execution time for each algorithm
- Test with arrays of different sizes (small, medium, large)
- Display time complexity analysis for each algorithm

### 🛠️ Implement Searching Algorithms

#### Description
Build efficient searching algorithms for sorted and unsorted data.

#### Requirements
Completed program should:

- Implement binary search for sorted arrays
- Implement linear search for comparison
- Handle edge cases (empty arrays, target not found)
- Analyze and display time complexity differences

### 🛠️ Performance Analysis and Optimization

#### Description
Analyze algorithm performance and explore optimization techniques.

#### Requirements
Completed program should:

- Create test cases with various data distributions (random, sorted, reverse-sorted)
- Measure and compare actual vs. theoretical time complexity
- Implement one optimization (e.g., hybrid sort or early termination)
- Document findings in comments or a separate analysis section
